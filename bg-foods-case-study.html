The challenge

I was contracted by Digital Yalo and worked alongside a team of about five other full-time developers on Yalo’s contract with B & G Foods. Our job was to recreate 45 child brand sites in WordPress. The biggest challenges were:

  • Source control implementation and management
  • Custom WordPress template creation
  • Extracting brand-specific data to fill WordPress templates for 45 brands
  • Recreating the corporate site’s advanced, JavaScript-driven components

My contribution

I rebuilt some of the 45 brand sites myself, but focused mostly on the highly specialized, configurable features of the corporate site:

  • JavaScript-driven components for the Brands and Investor Relations pages
  • Brands pages built on the WP REST API, with custom URL tags, permastructs and rewrites
  • A Node.js web scraper to move data over from the old sites
  • Server setups and a GitHub auto-deploy pipeline
  • Multilingual site setups (WPML)

I also wrote documentation and gave hands-on training to other developers on:

  • Local WordPress setup
  • WP Engine SSH key setup
  • Fail conditions and error logging for API request data

Highlighted work

I reverse-engineered the client’s keystone corporate site, with 31 unique API- and JavaScript-driven pages, custom URL structures and complex post-type relationships.
